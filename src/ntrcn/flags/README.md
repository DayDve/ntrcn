# Flags

`sprite.svg` contains the country flags of **vlags** (https://vlags.com), licensed under
CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).

Changes made for ntrcn: the 1:1 flags were put on a common 512×512 canvas and joined into
one SVG file, one `<g id="country code">` per flag. This file is distributed under the same
license, CC BY-SA 4.0.

# ntrcn

[![English](https://img.shields.io/badge/lang-en-blue.svg)](README.md)
[![Русский](https://img.shields.io/badge/lang-ru-red.svg)](README.ru.md)

Исправление текста, набранного в неправильной раскладке, для KDE Plasma 6 (Wayland).

Набрали `ghbdtn vbh` вместо `привет мир`, забыв переключить раскладку? Нажмите
<kbd>Pause</kbd> — текст исправится, а раскладка переключится, чтобы можно было печатать
дальше. Работает в любых приложениях, включая терминалы, и с любым числом раскладок.

## Возможности

- Исправляет последние набранные слова или выделенный текст и переключает раскладку.
- Где начинается ошибочная часть, определяется по словарям hunspell, поэтому правильно
  набранные слова перед ней остаются без изменений (`hello ghbdtn` → `hello привет`).
- Любое число раскладок; если их три и больше, нужную выбирают словари.
- Смена регистра выделенного текста.
- Индикатор в трее: флаг, название раскладки, то и другое, значок программы или ничего.
  Флагу можно назначить свою картинку.
- Звук при исправлении, автозапуск, страница диагностики.
- Интерфейс на английском и русском; переводы на другие языки приветствуются (см.
  [CONTRIBUTING.md](CONTRIBUTING.md)).

## Требования

- KDE Plasma 6 на Wayland
- Python 3.10+, PySide6, `python3-evdev`, `python3-dbus`
- `wl-clipboard`, `libxkbcommon`, `libhunspell`
- словари hunspell для ваших раскладок (необязательно, см. [Словари](#словари))

## Установка

### Пакет для Debian / Ubuntu / KDE neon

Для Debian 13+, Ubuntu 25.10+ и KDE neon. В более старых выпусках нет Plasma 6.

```bash
wget https://github.com/DayDve/ntrcn/releases/download/v0.1.0/ntrcn_0.1.0_all.deb
sudo apt install ./ntrcn_0.1.0_all.deb
sudo usermod -aG input $USER
```

После этого перезайдите в систему: членство в группе `input` (чтение клавиатур) и доступ к
`/dev/uinput` (его даёт правило udev из пакета) действуют с новой сессии.

### Из исходников

```bash
sudo apt install python3-evdev python3-dbus python3-pyside6.qtwidgets python3-pyside6.qtsvg \
    python3-pyside6.qtnetwork wl-clipboard libxkbcommon0 libhunspell-1.7-0
sudo usermod -aG input $USER
sudo install -m 644 src/ntrcn/70-ntrcn-uinput.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger /dev/uinput
make install-user   # ~/.local/bin/ntrcn, пункт меню, автозапуск
```

## Использование

| Клавиша | Действие |
| --- | --- |
| <kbd>Pause</kbd> | Перенабрать ошибочный текст перед курсором |
| <kbd>Pause</kbd> ещё раз | Тот же текст в следующей раскладке (при двух раскладках — отмена) |
| <kbd>Shift</kbd>+<kbd>Pause</kbd> | Перенабрать выделенное |
| <kbd>Ctrl</kbd>+<kbd>Pause</kbd> | Сменить регистр выделенного |

Это сочетания по умолчанию; меняются они в «Параметрах системы → Клавиатура → Комбинации
клавиш → ntrcn», как у любой программы KDE. Щелчок или прокрутка колёсиком над индикатором в
трее переключают раскладку, в его меню открываются настройки.

## Настройки

Настройки открываются из меню индикатора. Если индикатор выключен — повторным запуском
`ntrcn` из меню приложений или командой `ntrcn --settings`. Изменения применяются сразу и
хранятся в `~/.config/ntrcn/config.json`.

Свои картинки флагов кладутся в `~/.config/ntrcn/flags/<раскладка>.svg` или `.png`
(например, `de.png`) и подхватываются сразу.

Названия раскладок в подсказке и меню переводятся словарём xkeyboard-config. В Ubuntu и KDE
neon он входит в языковой пакет, например `sudo apt install language-pack-ru-base`; в Debian —
в `xkb-data`. После установки перезапустите ntrcn; всплывающее окно Plasma при смене раскладки
подхватит перевод после повторного входа в систему.

## Словари

Язык каждой раскладки берётся из реестра XKB, словари ищутся в `/usr/share/hunspell`,
`/usr/share/myspell` и `~/.local/share/hunspell`. Если для раскладки словаря нет,
перенабирается только последнее слово.

На странице диагностики в настройках видно, каких словарей не хватает, с командой установки
для вашего дистрибутива; там же их можно скачать из
[словарей LibreOffice](https://github.com/LibreOffice/dictionaries) в
`~/.local/share/hunspell`.

## Как это работает

ntrcn читает нажатия со всех клавиатур через evdev, не перехватывая их, и запоминает, какие
физические клавиши были нажаты и в какой раскладке. По <kbd>Pause</kbd> он переключает
раскладку через D-Bus Plasma, стирает текст клавишей Backspace и нажимает те же клавиши
заново на виртуальной клавиатуре (`/dev/uinput`). Выделенный текст берётся из primary
selection и набирается клавишами, найденными по раскладкам XKB.

## Приватность

ntrcn видит все нажатия клавиш, поэтому:

- нажатия хранятся только в памяти, не больше 256 последних, и стираются по Enter, щелчку,
  стрелкам и сочетаниям клавиш;
- набранный текст не пишется ни на диск, ни в лог, в том числе с `--debug`;
- в сеть программа обращается только для скачивания словаря, по кнопке.

Поле пароля ntrcn от других полей не отличает, а членство в группе `input` позволяет читать
клавиатуру любой вашей программе.

## Ограничения

- Только Plasma 6: раскладки переключаются через её D-Bus.
- Автодополнение и вставка не считаются набором; в таких случаях выделите текст и нажмите
  <kbd>Shift</kbd>+<kbd>Pause</kbd>.
- Словари не знают имён и терминов; такие слова в начале ошибочной части остаются как есть.
- При агрессивном энергосбережении звука (`power_save` у `snd_hda_intel`) начало звука может
  пропадать.

## Предыстория

Мне давно не хватало на Linux переключалки раскладки. Печатаю я десятью пальцами (спасибо
В. В. Шахиджаняну и его [«Соло на клавиатуре»](https://ergosolo.ru)), но бывает, что быстро
набрал фразу и только потом понял, что забыл переключить раскладку.

На X11 был [xneur](https://github.com/AndrewCrewKuznetsov/xneur-devel), но я давно на
Wayland, а там ничего достойного не нашлось. Я написал скрипт на bash в несколько строк: по
<kbd>Pause</kbd> он через `wl-clipboard` и `ydotool` копировал текст, перекодировал его и
вставлял обратно. Много лет им пользовался, но он очень костыльный и работает криво.

А ещё меня бесит, что в KDE Plasma нельзя поставить свою картинку флага на индикатор
раскладки. В KDE 4 достаточно было положить `flag.png` в папку в домашнем каталоге, в
Plasma 5 приходилось подменять системные файлы, а в Plasma 6 флаги рисуются из шрифта с
эмодзи и подменить их нечем. В Xfce, например, это до сих пор работает, но это не повод
переходить на него.

Так что я решил убить двух зайцев и сделать наконец полноценную переключалку, вспоминая
Punto Switcher, которым пользовался ещё до того, как его купил Яндекс.

Зачем я это делаю? Потому что могу.
